原严格要求合法四边形且每角不超过分析图对角线0.5%；合法50要求合法且四角各自距离真值不超过50个原图像素。表中现有集数字来自保存的训练设备预测；两新候选均已通过全部320 CPU/ONNX/MPS标志一致性回放，微小数值差不影响达标数。来源验证每次留出整个来源进行评估；四组反复用于研发，不是新的独立盲测。

V8.5改善现有集定位精度，来源的两种达标数有增有减，不能判断全面胜过V8.4。V8.6在现有集双标准全通过，但来源退化更明显。因此默认暂保留V8.4，使用全新、未参与训练的照片比较后再作决定。新照片测试时先保存各版本未经人工调整的结果，再人工确认；不要用调过的结果冒充检测结果。

## 文件与加载

- `photocut/models/v8_4/`：原默认模型，保持不变。
- `photocut/models/v8_5/`：V8.5.0归档候选。
- `photocut/models/v8_6/`：V8.6.0归档候选。

各新目录的`version.json`记录确认后的候选版本、模型SHA256与聚合指标。原始`manifest.json`保持已经验收的V8.4运行接口身份，因此可复用同一个运行时；接口版本和候选编号分别记录，不改写原实验清单。

程序化比较可以显式传入模型目录：

```python
from pathlib import Path
import photocut
from photocut.algorithms.v8_4.runtime import V84Runtime

models = Path(photocut.__file__).parent / "models"
v85 = V84Runtime(models / "v8_5")
v86 = V84Runtime(models / "v8_6")
# 对既有规范化输入调用 predict(loaded_input)，只生成待确认候选。
```

CLI默认仍是`--detector v8.4`；本次没有引入`--detector v8.5`或`v8.6`。所有候选仍须人工确认，不能凭合法几何自动裁剪。
